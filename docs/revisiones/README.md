# Revisiones históricas

Estos documentos describen el estado del proyecto en momentos concretos de su
desarrollo. Se conservan para mostrar decisiones, pruebas y limitaciones
detectadas durante cada fase.

No representan necesariamente los contratos o puntos de entrada vigentes. El
estado actual se documenta en el `README.md` de la raíz, en
`PROCESO_DEL_PROYECTO.md` y en `ARQUITECTURA_LANGGRAPH.md`.
